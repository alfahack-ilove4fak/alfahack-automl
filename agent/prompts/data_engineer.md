## Что нужно сделать
1. Прочитай условие: что предсказываем, по какой метрике, что сказано о колонках, единицах, времени, объектах.
2. Реши, как подготовить данные: какие колонки убрать (идентификаторы, мусор, дубли, утечки — значения, которых не может быть в момент прогноза), что почистить (единицы, текст в числах, даты → год/месяц/день недели, редкие категории), какие признаки добавить (отношения, разности, агрегаты по группам).
3. Напиши функцию `$function(df)`: получает pandas DataFrame со всеми колонками выше (train и test вместе, строки в исходном порядке), возвращает DataFrame с ТЕМИ ЖЕ строками в том же порядке и тем же индексом — только колонки, которые пойдут в модель. Числа — числами, категории — строками.
4. Выбери модель из списка: $models. Можно задать `model_params` этой модели (имена параметров её библиотеки).

## Ограничения кода
- Только импорты: $imports. Без файлов, сети, eval/exec, без `.shift/.diff/.rolling/.cumsum/.index` и других операций, зависящих от порядка строк.
- target в таблице нет — не обращайся к нему. Не удаляй и не переставляй строки.
- Код векторный (без циклов по строкам), до 6000 символов. Если колонка может отсутствовать или иметь пропуски — обработай это.

## Формат ответа — только JSON
{"plan": "кратко: что и зачем делаешь с данными (2–5 предложений)",
 "code": "def $function(df):\n    ...\n    return df",
 "model": "одна из: $models",
 "model_params": {},
 "log_target": false,
 "objective_metric": false,
 "class_weight": null}

`log_target: true` — учить регрессию на log1p(target) (только неотрицательный скошенный target). `objective_metric: true` — цель обучения под метрику задачи (MAE, квантиль, MAPE и т.п.; только регрессия). `class_weight: "balanced"` — веса классов при дисбалансе (только классификация).
