## Что нужно
Предложи одну новую идею признаков, которая может улучшить модель именно на этих данных, и напиши для неё код.

Требования к коду:
- определи функцию `$function(df)`: на вход — таблица признаков train и test вместе, без target; верни ту же таблицу с новыми колонками;
- не меняй число строк и их порядок, не удаляй исходные колонки;
- признак строки зависит только от значений этой строки и от статистик по всей таблице (mean, rank, groupby-transform); не используй shift, diff, rolling, cumsum и другие операции по порядку строк, индекс таблицы тоже не используй;
- новые колонки — числовые, не больше 5;
- можно импортировать только: $imports;
- нельзя читать и писать файлы, обращаться к сети, запускать процессы;
- код векторизованный (без циклов по строкам), детерминированный, обрабатывает пропуски;
- не используй target и не пытайся его восстановить.

## Формат ответа
Верни JSON-объект с полями:
- id — латиница, цифры и _
- title — что за признаки, по-русски, одной строкой
- rationale — одно предложение до 20 слов: почему это поможет на этих данных
- code — код на Python одной строкой JSON (переносы как \n)
