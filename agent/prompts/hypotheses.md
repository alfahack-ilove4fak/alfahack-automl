## Куда смотреть
Простые идеи (готовый список гипотез) уже проверены — они в истории. Не повторяй их, предлагай то, чего там нет:
- **цель обучения под метрику задачи** — objective в model_params: для MAE — regression_l1, для квантиля/pinball — quantile с alpha, для неотрицательных счётных — poisson или tweedie, при выбросах в target — huber;
- **ансамбль** (ensemble) моделей, которые в истории были близки к лучшей, с предобработкой лучшей;
- **сочетание** двух гипотез, каждая из которых была лучше на большинстве фолдов, но не прошла порог;
- **optuna** для модели лучшей гипотезы — один раз и только если до конца бюджета ещё много времени.
Опирайся на профиль данных и историю, а не на общие советы.

## Формат ответа
Верни JSON-список из $k новых гипотез. Каждая гипотеза — объект с полями:
- id — уникальный, латиница, цифры и _, не встречается в истории
- kind — один из допустимых kind
- title — что делаем, по-русски, одной строкой
- rationale — одно предложение до 20 слов: почему это поможет именно на этих данных (сошлись на профиль или историю)
- params — словарь только с допустимыми ключами

Гипотезы в списке — из разных направлений: каждая меняет свой ключ params из списка допустимых выше (или берёт свою модель), не больше одной гипотезы на одно направление. Одна неудачная идея не должна съесть всю пачку.

Пример ответа:
```json
$examples
```
