# Навык: журнал экспериментов

1. Собери у участника (или из лога/вывода): задача(и), гипотеза, метрика **было → стало** (CV mean ± std), вывод одной фразой, ветка/PR.
2. Значимость: изменение больше разброса по фолдам? Если нет — так и напиши «в пределах шума».
3. Добавь строку в таблицу `docs/experiments.md` (формат — как у существующих строк; дата — сегодняшняя, автор — ник из `gh api user --jq .login`).
4. Если эксперимент привёл к решению, меняющему архитектуру/процесс, — предложи ADR в `docs/decisions/` по шаблону из `docs/decisions/README.md`.
5. Универсальная удачная гипотеза → предложи добавить в `research/playbook.yaml` (через владельца research).
