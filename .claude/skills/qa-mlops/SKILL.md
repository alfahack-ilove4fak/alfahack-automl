# Навык: качество и запуск

Пакет роли: `docs/roles/qa.md` · материалы: `docs/resources/qa.md` · модуль: `evaluation/CLAUDE.md`.

## Формула балла (приложение 3 кейса)
- Регрессия: `S = 100 · max(0, 1 − RMSE / B_RMSE)`; классификация: `S = 100 · max(0, (MacroF1 − B_F1) / (1 − B_F1))`; public = среднее двух.
- `B_*` — метрики бейзлайна организаторов (неизвестны). Локально заменяем своим простым бейзлайном и следим за **относительными** изменениями.

## Рецепт: харнесс
1. Из `train.csv` задачи отрезать 20–30% (стратифицированно для классификации) → «скрытый тест» + `answers.csv`.
2. Собрать папку задачи в формате платформы, запустить `solution.py` отдельным процессом с `AGENT_TIME_BUDGET_SEC`.
3. Посчитать метрику (реестр `evaluation/metrics.py`) и балл; сохранить строку в CSV-отчёт (дата, коммит, задача, метрика, балл, время, пик RAM).
4. Режим `--all` для `tasks/public` и `tasks/practice`.

## Рецепт: проверка перед сабмитом (`scripts/pre_submit.py`)
ZIP → распаковать во временную папку → чистое окружение (`uv venv` + `requirements.txt`) → запуск на копиях задач с лимитом времени → `validate_submission` → отчёт. Плюс: импорты только из `requirements.txt`, нет сетевых вызовов.

## CI
Бюджет 2000 мин/мес. Быстрые тесты на каждый PR; тяжёлые (группа `full`, 3-часовые прогоны) — только вручную (`workflow_dispatch`) или по расписанию.
