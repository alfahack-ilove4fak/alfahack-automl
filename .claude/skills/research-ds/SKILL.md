# Навык: исследования и playbook

Пакет роли: `docs/roles/research.md` · материалы: `docs/resources/research.md` · модуль: `research/CLAUDE.md`.

## Рецепт: от идеи до строки в playbook
1. Идея → issue по шаблону «Гипотеза» (обязательно ответ «универсальна ли?»).
2. Проверка в ноутбуке/скрипте на **обеих** публичных и тренировочных задачах, одинаковая CV (5 фолдов, SEED 42).
3. Значимо, если улучшение больше разброса по фолдам. Записать в `docs/experiments.md`: было → стало → вывод.
4. Работает на большинстве задач → PR в `research/playbook.yaml` (поля в шапке файла). Нужен новый ключ `params` → сначала договориться с ML-инженером.

## Рецепт: тренировочная «скрытая» задача
Формат как у платформы: папка с `task.md` + `train.csv`, `test.csv`, `sample_submission.csv`, `data_dictionary.csv`, плюс **скрытый** `answers.csv` для харнесса QA. Источники без интернета: `sklearn.datasets` (breast_cancer, wine, diabetes, digits), перемешанные/урезанные публичные задачи с другой метрикой (MAE вместо RMSE, ROC-AUC на бинарной версии). Меняй формулировки и пути в `task.md` — агент должен справляться.
