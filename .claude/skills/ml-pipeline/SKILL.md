# Навык: ML-пайплайн для универсального агента

Пакет роли: `docs/roles/ml.md` · материалы: `docs/resources/ml.md` · модуль: `ml/CLAUDE.md`.

## Рецепт: добавить новый вариант в run_experiment
1. Придумай ключ `params` (например, `model: catboost`) и опиши его в docstring `ml/experiment.py`.
2. Реализуй ветку: модель создаётся по `params`, всё обучаемое — внутри фолда.
3. Предсказание — в виде, который нужен метрике (`METRICS[spec.metric.name].prediction`).
4. Обработай время: проверка `budget.has_time()` между фолдами; для медленных моделей — меньше фолдов или подвыборка, записать это в `ExperimentResult.error`/лог.
5. Добавь пример гипотезы в `research/playbook.yaml` (через research) и тест в `tests/unit` на маленьких данных.
6. Сообщи agent-инженеру новый ключ (стыковка в 13:00).

## Принципы
- Бустинги — основа для таблиц; CatBoost сильнее на категориях, LightGBM быстрее.
- Классификация: стратифицированные фолды; Macro F1 чувствителен к редким классам (веса классов, пороги — подбирать только на OOF).
- Регрессия: смотри на распределение target и выбросы; log-преобразование — гипотеза, а не правило (RMSE считается в исходной шкале).
- Если в данных есть «группы» (одно здание в разные годы) — случайные фолды завышают оценку; GroupKFold/по времени — гипотеза для проверки.
- Память: оценивай размер матрицы до обучения; на платформе 32 ГБ, у нас 14–16 ГБ.
