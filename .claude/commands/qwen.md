description: Проверить Qwen и бюджет, прогнать агента с LLM или сравнить «без LLM / с Qwen»
---

Помоги участнику поработать с Qwen. Правила и факты — @docs/qwen.md. `.env` не читай и ключ не проси.

1. Запусти `uv run python scripts/qwen.py check` и `uv run python scripts/qwen.py budget`. Если ключа нет локально — объясни облачный путь: Actions → qwen → Run workflow (режимы check / run / compare) и дай ссылку на вкладку Actions репозитория.
2. Спроси, что нужно: связь, прогон агента с Qwen на задаче или сравнение с харнессом. Перед `run`/`compare` назови ожидаемый расход (минуты, примерно ₽) и остаток бюджета.
3. После прогона разбери: строки `Итерация … [llm]` и `LLM итог` в `agent.log`, `llm_calls.jsonl` (зачем звали, токены, ответы). Что предложила LLM, что принято, сколько стоило.
4. Ошибки — по таблице «Если не работает» из docs/qwen.md. Повторяющийся сбой — предложи написать в чат команды с выводом `qwen.py check`.
5. Напомни: при равном балле решают токены — новый вызов LLM только с выигрышем в харнессе.
