Объясни участнику: $ARGUMENTS

Правила:
- Сначала одной-двумя фразами — суть простыми словами, без жаргона. Если есть в `docs/glossary.md` — опирайся на него.
- Потом — «зачем это в нашем проекте» (где используется: файл и строка).
- Если это код — пройди по нему сверху вниз, крупными блоками, не построчно. Покажи маленький пример запуска (`uv run python -c ...` или тест).
- Если это ML-концепция — интуиция → маленький пример на числах → формула (если нужна) → типичные ошибки.
- Ссылки — только проверенные: `docs/resources/<роль>.md` или официальная документация (через context7). Не уверен — ⚠️.
- В конце: «Хочешь глубже — спроси про X» (1–2 варианта) и, если термина нет в глоссарии, предложи добавить.
Длина — до ~25 строк, если участник не попросил подробнее.
