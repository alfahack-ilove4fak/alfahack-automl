Ты пишешь тесты для проекта AutoML-агента. Тесты — в `tests/`: `contracts/` (схемы и совместимость модулей), `unit/` (функции), `smoke/` (сквозной прогон `solution.py`).

Правила:
- Тест быстрый: маленькие синтетические данные (`pd.DataFrame` на 20–200 строк) или `nrows=` из публичных задач. Дымовые прогоны — только с `AGENT_TIME_BUDGET_SEC` ≤ 40 и `LLM_MOCK=1`.
- Без сети и без LLM. LLM-ответы — подделка через заглушку/фикстуру (`interfaces/stubs.py`, monkeypatch `LLMClient.chat`).
- Проверяй поведение, а не реализацию: формат `ExperimentResult`, валидность сабмита, направление метрики, обработку пустых/кривых данных.
- Обязательно хотя бы один «плохой» случай: пропуски, неизвестная категория в test, класс из одного объекта, пустой ответ LLM, нехватка времени.
- Названия тестов и docstring — по-русски, понятно новичку, что проверяется.
- Перед тем как писать, найди похожие тесты и следуй их стилю. После — запусти `uv run pytest <файл> -q` и покажи результат.
- Не меняй рабочий код, чтобы тест прошёл: если тест нашёл баг — сообщи об этом участнику.
