# Ответы организаторов в чате хакатона (кратко)

Собрано 2026-10-21 из переписки в чате хакатона 19–21.10 (прислал капитан). Это пересказ, а не цитаты; первоисточник — официальный чат. Если организаторы изменят правила, обновите файл. Правила сдачи — в `platform_instructions.md`.

## Ключ и модель Qwen
- Ключи для команд отправляются **капитанам на почту** (обещали 20.10 в течение дня).
- Из контейнера на платформе интернета нет; Qwen доступна из `solution.py` через специальный API-эндпоинт (переменные `OPENAI_API_KEY`, `OPENAI_MODEL`, `OPENAI_BASE_URL` задаёт платформа).
- Параметры модели (температура и т. п.) организаторами не заданы — можно указывать свои.
- Остаток по ключу проверяется запросом `GET https://changellenge.up.railway.app/key/info` с заголовком `Authorization: Bearer <ключ>`. Цену токена организаторы не назвали, дали только эту ссылку.

## Лимиты
- **600 ₽ в сутки — только на время разработки.** Запуск решения на платформе в этот лимит не входит; на платформе нет ограничения на число вызовов и расход токенов, есть только лимит времени скрипта.
- 3 часа — **на каждую задачу отдельно**, а не суммарно. Две задачи запускаются **параллельно**, каждая в своём каталоге со своим `task.md`; результаты между запусками не передаются.
- Распределять время между задачами вручную не нужно: агент сам укладывается в 3 часа и пишет `submission.csv`. По истечении времени засчитывается то, что успело получиться.
- Диск: отдельной квоты нет, ориентировочно 30–35 ГБ свободно (на вебинаре назвали **30 ГБ**); файлы и подкаталоги можно создавать в каталоге задачи и в `/tmp`.

## Контейнер и зависимости
- Пакета **`mcp` в контейнере нет**. Инструменты для модели предоставляет сам скрипт сабмита: модель выбирает действие, скрипт выполняет. (В `baseline.py` импорт `mcp` есть, но в своём коде мы его не используем.)
- `requirements.txt` — фиксированный список для всего: агента, его инструментов и генерируемого кода. Библиотеки в ZIP (в том числе `.whl`) добавлять нельзя. Нужна дополнительная библиотека или модель — писать в чат, добавят после согласования с экспертами.
- **`git` в контейнере недоступен.** Для разработки можно использовать любой (в том числе приватный) репозиторий, но код во время запуска из него не загрузить: всё должно быть в ZIP.
- Во всех задачах (и в private) — только текстовые или табличные данные; изображения, аудио и видео поддерживать не нужно. **Уточнение с вебинара:** задач по анализу текстов (NLP), CV и рекомендательных систем не будет — это табличные задачи, текстовые колонки возможны.

## Оценка и сабмиты
- Описание задач в `task.md` оформлено по единому шаблону — ориентироваться на примеры регрессии и классификации.
- Public и private считаются **отдельно**; в каждом случае итог — среднее арифметическое баллов по двум соответствующим задачам.
- В зачёт идёт лучшее решение, даже если оно было не последним.
- Каждая отправка — отдельный сабмит. **Не отправлять повторно, пока не появился скор предыдущего.** Нулевой скор виден в интерфейсе; сообщение «не побило бейзлайн» означает, что решение не лучше бейзлайна.
- 3 сабмита в день, обновление в 00:00 МСК. Обработка может быть долгой (до 3 часов на сабмит, плюс очередь на серверах — 20–21.10 организаторы решали проблему с очередью).
- Подробные логи прогона доступны только администраторам: нужно написать название команды и время отправки.
- Частая причина нулевого балла у других команд: файлы во вложенных папках ZIP. Платформа копирует только корневые `.py` и `requirements.txt` (у нас это закрыто самораспаковывающимся `solution.py`, ADR 0007).

## Всё ещё не выяснено
- Точное время окончания приёма сабмитов.
- Формат защиты и питча.
- Цена токена Qwen в рублях (для учёта ₽ в агенте при разработке; остаток можно смотреть через `/key/info`).
