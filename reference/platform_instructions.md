# Инструкция платформы Boosters — трек «AI-агент для разработки ML-моделей» (онлайн-тур)

Скопировано со страницы кейса на платформе 2026-10-20 (прислал капитан). Первоисточник правил сдачи — эта страница; если она изменится, обновите файл.

## Формат сдачи
На платформу загружается ZIP-архив с решением. В корне архива должен лежать файл `solution.py` — единая точка входа для запуска агента. Логику можно распределить по нескольким модулям внутри того же архива: `solution.py` импортирует их и вызывает нужный код. Платформа запускает решение в Docker-контейнере.

Переменные окружения, интерфейс запуска и формат вывода зафиксированы в `baseline.py`. Решение должно строго соблюдать этот интерфейс.

Число сабмитов в день на команду — 3. Обновляется в 00:00 МСК.

## Что положить в ZIP
Все файлы должны лежать **в корне архива, без папок**:
- `solution.py` — точка входа;
- `requirements.txt` — предоставленный список зависимостей;
- дополнительные `.py`-модули, если нужны.

**В каталог задачи копируются только корневые `.py`-файлы и `requirements.txt`.** Вложенные папки и остальные файлы — данные, `.whl`, конфиги — не копируются. Если модуль в подпапке, при запуске он будет недоступен и решение может получить 0 баллов.

Сторонние пакеты и `.whl` добавлять нельзя. Зависимости устанавливает платформа из корневого `requirements.txt`. Запуск собственного `pip` из `solution.py` недоступен.

## Как запускается
Платформа копирует файлы в каталог задачи и выполняет: `python3 solution.py task.md`.
Скрипт работает в одной папке с `task.md`. Итоговый `submission.csv` — туда же.
Промежуточные файлы можно создавать в каталоге задачи, его подкаталогах и в `/tmp`. Запрет на папки касается только загружаемого ZIP.

## Лимиты
ZIP — до 100 МБ · 8 CPU и 32 ГБ RAM на запуск задачи · до 3 часов.

## Проверка в Boosters
После загрузки: проверка загрузки → очередь. «Решение находится на проверке» — принято в очередь, это ещё не результат. После проверки — «Точность вычисления: …».

## Ошибки загрузки
| Сообщение | Что делать |
|---|---|
| «Выберите файл решения» | Прикрепите ZIP |
| «Допустимы только файлы CSV или ZIP» | Загрузите ZIP по инструкции |
| «Файл пустой» | Проверьте содержимое архива |
| «Размер файла не должен превышать 128 мегабайт» / «Файл решения слишком большой» | Лимит трека — 100 МБ |
| «В файле решения ошибки: …» | Исправьте перечисленное |
| «Не удалось загрузить файл» / «…публичную ссылку…» / «Не удалось отправить решение» | Повторите; не помогает — к организаторам |
| «Задание ещё готовится» / «Команда ещё подключается…» / «Ваш профиль ещё синхронизируется» | Подождите и отправьте снова |
| «Вы исчерпали лимит попыток» | Лимит исчерпан |
| «Команда не допущена…» / «дисквалифицирована» / «Вы не состоите в этой команде» | К организаторам |

## Ошибки во время проверки
| Сообщение | Что проверить |
|---|---|
| «Ошибка формата данных» | Соответствие файлов требованиям задачи |
| «Превышено время обработки решения» | Длительность скрипта, включая обращения к модели |
| «Не хватает данных в решении» | Скрипт формирует все результаты |
| «…отсутствует файл …» | Файл создаётся и лежит рядом с `task.md` |
| «Ошибка скоринга сабмита. Попробуйте позже» | Повторить позже; иначе — к организаторам |

При обращении к организаторам приложите текст ошибки или скриншот и время отправки.
