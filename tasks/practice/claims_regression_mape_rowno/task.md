# Сумма страховой выплаты

## Задача

Оцените сумму выплаты по страховому убытку. Важна относительная точность: ошибиться на 10 000 ₽ в выплате на 20 000 ₽ хуже, чем в выплате на 500 000 ₽.

## Данные

- `train.csv` — 20000 строк с признаками и таргетом;
- `test.csv` — 5000 строк без таргета;
- `data_dictionary.csv` — описание полей;
- `sample_submission.csv` — шаблон ответа; значения в нём не являются правильными ответами.

CSV в UTF-8, разделитель — запятая, десятичный разделитель — точка. Пустая ячейка — пропуск.

## Описание полей

`record_no`, `vehicle_age`, `driver_age`, `sum_insured`, `prior_claims`, `deductible` — числа; `region`, `policy_type`, `channel` — категории.

## Что предсказать

Для каждой строки `test.csv` — положительное число `claim_amount`.

Метрика — **MAPE, mean absolute percentage error (меньше — лучше)**.

## Формат результата

Файл `submission.csv` в каталоге этого файла, ровно два столбца:

```csv
id,claim_amount
```

Для каждого `id` из `test.csv` — одно предсказание, порядок строк как в `test.csv`.
