# Мошеннические платежи

## Задача

Найдите мошеннические операции по картам. Мошенничество редкое — около 2–3% операций. В train — операции за январь–сентябрь 2024 года, в test — за октябрь 2024 года.

## Данные

- `train.csv` — 60000 строк с признаками и таргетом;
- `test.csv` — 15000 строк без таргета;
- `data_dictionary.csv` — описание полей;
- `sample_submission.csv` — шаблон ответа; значения в нём не являются правильными ответами.

CSV в UTF-8, разделитель — запятая, десятичный разделитель — точка. Пустая ячейка — пропуск.

## Описание полей

`date` — дата строкой; `merchant_id`, `merchant_category`, `device`, `country` — категории; `hour`, `amount`, `customer_age`, `tx_last_24h` — числа; `is_foreign` — флаг.

## Что предсказать

Для каждой строки `test.csv` — метка `is_fraud`: 1 (мошенничество) или 0.

Метрика — **F1-score по классу 1 (больше — лучше)**.

## Формат результата

Файл `submission.csv` в каталоге этого файла, ровно два столбца:

```csv
id,is_fraud
```

Для каждого `id` из `test.csv` — одно предсказание, порядок строк как в `test.csv`.
