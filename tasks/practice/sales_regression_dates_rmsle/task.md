# Дневные продажи в магазинах

## Задача

Оцените, сколько штук товара категории продаст магазин за день. В train — продажи за 2023–2024 годы, в test — за первый квартал 2025 года.

## Данные

- `train.csv` — 30000 строк с признаками и таргетом;
- `test.csv` — 6000 строк без таргета;
- `data_dictionary.csv` — описание полей;
- `sample_submission.csv` — шаблон ответа; значения в нём не являются правильными ответами.

CSV в UTF-8, разделитель — запятая, десятичный разделитель — точка. Пустая ячейка — пропуск.

## Описание полей

`date` — дата строкой; `store_id`, `city`, `store_type`, `product_category` — категории; `promo`, `is_holiday` — флаги; `price`, `temperature` — числа с пропусками.

## Что предсказать

Для каждой строки `test.csv` — неотрицательное число `units_sold`.

Метрика — **RMSLE, root mean squared log error (меньше — лучше)**.

## Формат результата

Файл `submission.csv` в каталоге этого файла, ровно два столбца:

```csv
id,units_sold
```

Для каждого `id` из `test.csv` — одно предсказание, порядок строк как в `test.csv`.
