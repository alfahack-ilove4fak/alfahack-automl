# Роль: Исследователь / Data Scientist (`research`)

**Ты — знания и честность команды**: что работает на табличных задачах вообще (а не только на наших двух), как проверить, что улучшение настоящее, и как рассказать об этом жюри. Ты владелец playbook, тренировочных задач и питча.
**Твоя зона:** `research/`, `tasks/practice/`, `docs/pitch/`. **Ревьюит тебя:** ml. **Ты ревьюишь:** ml.
**Материалы:** [docs/resources/research.md](../resources/research.md) · **Модуль:** [research/CLAUDE.md](../../research/CLAUDE.md)

## 3.1 Установка (сверх [docs/install.md](../install.md))

Графики и ноутбуки:
```
uv sync --group research
```
**Проверка:** `uv run python scripts/doctor.py --role research` → `✅ библиотеки роли research`.
Ноутбуки — в VS Code (расширения Python + Jupyter), ядро — `.venv` проекта (VS Code предложит сам; если нет — `Ctrl+Shift+P → Python: Select Interpreter → .venv`).
Для проверки идей на CatBoost/XGBoost понадобится ещё `uv sync --group full` (⚠️ тяжело — можно в Codespaces).

## 3.2 Git в твоей роли

Общий гайд — [docs/git-guide.md](../git-guide.md). Для тебя важно:
- Ветки: `research/<задача>` — например `research/playbook-v1`, `research/practice-tasks`.
- **Ноутбуки:** перед коммитом очищай вывод (VS Code: `Clear All Outputs`), иначе PR на мегабайты и конфликты. Кладём в `research/notebooks/`.
- `research/playbook.yaml` едет на платформу — PR в него ревьюит ml (проверяет, что `params` поддерживаются).
- Журналы `docs/experiments.md` и `docs/pitch/` правят все — делай маленькие PR, чтобы не ловить конфликты (git-guide, раздел 6).

## 3.3 Рабочие инструменты по кейсу

| Инструмент | Зачем тебе |
|---|---|
| Jupyter (через VS Code) + pandas | EDA публичных задач |
| matplotlib, seaborn | графики для анализа и для питча |
| scikit-learn: `sklearn.datasets` | данные для тренировочных задач **без интернета** (breast_cancer, wine, diabetes, digits) |
| scikit-learn: KFold / GroupKFold / TimeSeriesSplit | исследование схем валидации |
| `research/playbook.yaml` | твой главный продукт для агента |
| `scripts/run_local.py`, харнесс QA | проверка гипотез на всех задачах |
| `docs/experiments.md`, `docs/submissions.md` | цифры для выводов и питча |
| PDF кейса (`reference/`) | формулы баллов, что ценит жюри (AutoResearch, честная оценка) |
