# Роль: Капитан / интегратор (`captain`)

**Ты склеиваешь всё в работающий продукт и ведёшь команду**: `solution.py`, бюджет времени/памяти, релизы и сабмиты, контракты, ритм дня, общение с организаторами.
**Твоя зона:** `solution.py`, `runtime/`, `interfaces/` (по процессу), `.github/`, `.claude/`. **Ревьюит тебя:** qa. **Ты ревьюишь:** PR с `interfaces/`, оркестрацию agent, сливаешь `dev → main`.
**Материалы:** [docs/resources/captain.md](../resources/captain.md) · **Модуль:** [runtime/CLAUDE.md](../../runtime/CLAUDE.md)

## 3.1 Установка (сверх [docs/install.md](../install.md))

- Право на доску задач: `gh auth refresh -s project` → проверка: `gh auth status` содержит `project`.
- Для тестов всего агента: `uv sync --group full` (⚠️ тяжело — или в Codespaces).
**Проверка:** `uv run python scripts/doctor.py --role captain`.

## 3.2 Git в твоей роли

Общий гайд — [docs/git-guide.md](../git-guide.md). Только у тебя:
- **Слияние `dev → main`** — PR «релиз: …», ревью QA, `gh pr merge <N> --merge` (без squash — чтобы история `dev` сохранилась в `main`).
- **Теги сабмитов:** `git tag sub-ГГГГ-ММ-ДД-N origin/main && git push origin sub-ГГГГ-ММ-ДД-N`.
- **PR с `interfaces/`** сливаешь ты, после одобрения всех затронутых владельцев.
- **Подключение участника:** `python3 scripts/add_member.py --name <латиница> --github <ник> --role <роль>` → слить созданный PR.
- **Сторож веток** создаёт issue «⛔ Нарушение правил» — разбери: случайность → объяснить; нужно откатить → `git revert` в новом PR.
- **Задачи на доске:** правишь `docs/roles/tasks.yaml` → `uv run python scripts/tasks.py render` → PR; новые задачи на доску — `uv run python scripts/tasks.py issues`.

## 3.5 Claude Code в твоей роли

- **Скилл** `captain-integration` — рецепты окна интеграции, релиза, подключения участника; `submission-format` — правила сдачи.
