1. **[#206](https://github.com/alfahack-ilove4fak/alfahack-automl/issues/206) — на 3 из 10 задач агент хуже LightGBM по умолчанию.** На платформе это 0 за задачу: бейзлайн организаторов — «простейшая модель руками DS». Самое быстрое и прямое улучшение.

Всё остальное — после этих трёх или если ты не можешь помочь с ними.

## 3. Правила (обновлены)

1. **Каждое изменение качества — с харнессом до/после** в PR (минимум public-пара; для #200/#206 — все 10 задач). Нет таблицы — не сливаем.
2. **Минуты GitHub Actions на исходе** (#205): тесты и `ruff` — **локально до пуша**; не пушить по коммиту «посмотреть CI»; Windows-проверка — только вручную. Бот сливает PR на событиях и в окна **13:00, 18:30, 19:00 МСК**.
3. **Очередь ревью важнее нового кода.** Сейчас ~10 PR с `ready` ждут одобрения — каждый вечером проверь, нет ли PR, где ревьюер ты (`requested_reviewers`), и разбери до синка.
4. **Никаких подгонок под публичные задачи** — только то, что поможет на любой табличной задаче.
5. **Агент не падает**: любая ошибка → `FAILED` у гипотезы, ответ в `submission.csv` всегда валиден.
6. **Каждый эксперимент — строка в [experiments.md](experiments.md)**, каждый сабмит — в [submissions.md](submissions.md) с локальным баллом рядом с public.
7. **Заморозка кода — 26.10 в 18:00.** Новые большие фичи — не позже 25.10.
