# Агент, который не обманывает сам себя

**AutoML-агент для табличных задач:** читает `task.md`, сам ставит эксперименты, принимает только то, что выдерживает честную проверку.

Команда alfahack-automl · Альфа Хак 2026

## 1. Проблема

- Каждая новая ML-задача — дни одного и того же цикла: данные → бейзлайн → гипотезы → проверка.
- AutoML перебирает модели, но **не спрашивает, почему** модель ошибается.
- LLM-агенты спрашивают — и **взламывают собственную метрику**.

## 2. Принцип: сначала надёжно, потом умно

```
task.md → разбор задачи → тривиальный ответ (секунды) → бейзлайн → цикл гипотез
                                   ↓                          ↓            ↓
                           submission.csv валиден в любой момент — каждый новый лучший сразу записан
```

- Сторож: 3 часа, память, ₽ на LLM — ответ есть всегда, даже если всё остальное упало.
- Балл = 0, если хуже бейзлайна организаторов → сначала гарантируем ответ, потом улучшаем.

## 3. Понимает незнакомую задачу

- Сам находит файлы, таргет, id, метрику — **путям и формату из текста не верит**.
- LLM-аналитик (Qwen) читает `task.md`, агент сверяет его ответ с данными.
- Проверено на **10 задачах с 10 разными метриками** (2 public + 8 наших «скрытых» с ловушками).

## 4. Решает LLM — цикл AutoResearch

- Qwen читает задачу и паспорт данных, предлагает гипотезы, **смотрит на результат и меняет направление**.
- Playbook проверенных идей — первым (ADR 0014), LLM — когда он исчерпан и для разбора задачи.
- Живой прогон с Qwen (public/multiclass): гипотеза **от LLM** принята — Macro F1 **0.571 → 0.620**, 5/5 фолдов, **0.68 ₽**.

⏳ 2–3 решения Qwen из лога полного прогона: «предложила → проверили → приняли / отклонили, потому что…»

## 5. Честная самооценка — главное

- Обычная кросс-валидация и честная проверка **расходятся по знаку**: регрессия — KFold 41.95 против 46.92 по времени.
- Агент сам выбирает схему проверки, похожую на скрытый test: **время → дубликаты → обычная CV** (ADR 0013).
- Гипотеза принимается, только если лучше на тех же фолдах с запасом на шум (t ≥ 2).

## Запасной: устойчивость

- LLM недоступна или ответила мусором → playbook; падение гипотезы → `FAILED`, а не крах.
- Разбор задачи упал → ответ всё равно пишется (#187).
- Бейзлайн упал → лестница отступления, а не 0 баллов (#171, #176).
