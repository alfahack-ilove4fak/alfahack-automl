## Из вебинара организаторов — что это значит для тебя
Полный разбор: [`docs/resources/webinar-qa.md`](../../resources/webinar-qa.md) (метки времени — в расшифровке `reference/webinar_transcript.md`).

- **Один запуск на скрытую задачу, перезапуска нет** (только при сбое платформы); упавшая задача = минимальный балл, вторая остаётся. Значит, робастность (`AnswerKeeper`, сторож, запас по времени/RAM) важнее среднего выигрыша.
- **Харнессу и тренировочным задачам не хватает** (передай Роме списком): мультитаргет, вероятностный ответ, ранжирование, редкие классы, новые категории в test, даты строкой, расхождение словаря с `train`, пустые/малые тесты.
- **Логируй в харнессе токены и время** каждого прогона — это тай-брейки платформы (токены → время).
- **Чек-лист сабмита (#49) дополни:** ZIP ≤ 100 МБ; нет `.whl` и исходников чужих библиотек внутри; чистая среда без кэшей (платформа не хранит файлы прошлых запусков) — проверяй запуск из пустой папки; seed зафиксированы.
- **Репетиция 3 ч (#47):** 32 ГБ нужны на **каждую** из двух параллельных задач; диск 30 ГБ — следи за объёмом промежуточных файлов.
- **Нельзя воспроизвести платформу локально** (Docker-образ не дают) — единственная проверка «как на платформе» это сабмит.
