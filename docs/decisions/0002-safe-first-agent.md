# 0002. Агент «сначала надёжно, потом умно»

- Дата: 2026-10-20 · Кто: @thenlaooo · Статус: принято

## Контекст
- Балл = 0, если результат не лучше бейзлайна организаторов. Падение или пустой файл — тоже 0.
- LLM — Qwen (~27B), заметно слабее топовых моделей в длинных рассуждениях; бывает медленной/недоступной.
- Итог решают две скрытые задачи с неизвестной метрикой. На private берут версию с лучшим public.

## Решение
1. Сразу после разбора задачи пишем тривиальный ответ (среднее / частый класс).
2. Детерминированный бейзлайн (LightGBM + CV) без LLM — валидный хороший ответ за минуты.
3. Цикл AutoResearch: гипотезы от LLM (или из playbook, если LLM нет) → CV → принимаем, только если лучше с учётом шума фолдов → сразу перезаписываем ответ.
4. Агент сам находит файлы и метрику, не доверяя путям из `task.md`.

## Альтернативы
- «LLM пишет весь код» (как `baseline.py` организаторов) — гибко, но хрупко: одна ошибка модели = 0 баллов.
- Чистый AutoML (AutoGluon) без агента — не отвечает на суть кейса (гипотезы, AutoResearch) и тяжёл по памяти.

## Последствия
- Ответ есть всегда; LLM только улучшает.
- Нельзя «подгонять» агента под публичные задачи: всё должно работать на любой табличной задаче. Проверяем на `tasks/practice/`.
