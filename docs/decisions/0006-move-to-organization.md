# 0006. Переезд в организацию alfahack-ilove4fak

- Дата: 2026-10-20 · Кто: @thenlaooo · Статус: принято

## Контекст
Репозиторий и доска жили на личном аккаунте капитана. Проблемы: чат claude.ai у участников не видел приватный репозиторий чужого аккаунта; доступ к доске приходилось выдавать каждому отдельно; всё держалось на одном аккаунте.

## Решение
Организация `alfahack-ilove4fak` (Free): репозиторий перенесён (история, ветки, PR, задачи сохранились, старые адреса GitHub перенаправляет), новая доска `orgs/alfahack-ilove4fak/projects/1`, право записи участникам — через базовые права организации, приложение Claude установлено на организацию (только этот репозиторий).
Все адреса — в одном файле `scripts/team_config.py`; состав команды и статусы приглашений — `scripts/team_sync.py`.

## Альтернативы
- Остаться на личном аккаунте и поставить приложение Claude туда — решает только чат, остальное нет.
- GitHub Team (платно) — дал бы защиту веток, но не нужен на неделю.

## Последствия
- Защиты веток по-прежнему нет (Free) — 4 слоя из ADR 0003 остаются.
- Codespaces для Free-организации оплачивает сам участник — его личный бесплатный лимит, репетиции не ломаются.
- Новый участник: `add_member.py` приглашает в организацию; капитану для себя — только с `--skip-invite` (иначе понизит владельца до участника).
