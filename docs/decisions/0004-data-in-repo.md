# 0004. Данные организаторов лежат в git

- Дата: 2026-10-20 · Кто: @thenlaooo · Статус: принято

## Контекст
Данные — 83 МБ CSV, самый большой файл 42 МБ (лимит GitHub — 100 МБ на файл). Оригинал — в Google Drive организаторов (ссылки в PDF). Цель — онбординг за час.

## Решение
Данные лежат в `tasks/public/<задача>/` в том же виде, что и у платформы: `task.md` + CSV рядом. Файлы организаторов без изменений — в `reference/`. CSV помечены в `.gitattributes` как `-text`: git не трогает их побайтно.

## Альтернативы
- Скачивание скриптом с Google Drive — ещё одна точка отказа (лимиты Drive, медленная сеть, лишняя библиотека).
- Git LFS — лишняя сложность для новичков, квота на бесплатном тарифе.

## Последствия
- `git clone` даёт всё сразу; тесты и CI работают на настоящих данных.
- Тяжёлые артефакты (модели, предсказания, `submission.csv`) в git не кладём — они в `.gitignore`.
