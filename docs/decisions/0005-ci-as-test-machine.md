# 0005. Проверка кода в GitHub Actions и Codespaces

- Дата: 2026-10-20 · Кто: @thenlaooo · Статус: принято

## Контекст
- Ни у кого в команде нет машины с 32 ГБ, как на платформе.
- Интернет на буткемпе медленный (у капитана 15–45 КБ/с): поставить все зависимости локально — часы.
- Codespaces для нашего аккаунта предлагает только 2 ядра/8 ГБ и 4 ядра/16 ГБ (проверено через API 20.10); 120 ядро-часов в месяц на человека.

## Решение
- CI (GitHub Actions) — главная «чистая машина»: на каждый PR ставит зависимости с нуля и прогоняет тесты, включая дымовой запуск `solution.py`. 2000 минут/мес хватает.
- Генеральные репетиции (3 часа) — в Codespaces 4 ядра/16 ГБ (~30 часов на человека в месяц).
- Агент сам подстраивается под доступную память (`runtime/budget.py` читает и лимит Docker).

## Альтернативы
- Kaggle Notebooks — ⚠️ данные о памяти CPU-сессий расходятся (16 или 30 ГБ); можно проверить вручную как запасной вариант.
- Арендовать сервер — нет бюджета и времени.

## Последствия
- Полной копии платформы (8 CPU/32 ГБ) у нас нет: запас по памяти держим с коэффициентом, тяжёлые методы проверяем на 16 ГБ.
