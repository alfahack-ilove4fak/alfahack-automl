# 0001. Python 3.12 + uv, зависимости группами

- Дата: 2026-10-20 · Кто: @thenlaooo · Статус: принято

## Контекст
Платформа — Python 3.12 и фиксированный `requirements.txt` (≈ 40 пакетов, включая torch, autogluon, lightautoml — это гигабайты). Ноутбуки команды на разных ОС, системный Python у всех разный (у капитана 3.14). Интернет на буткемпе медленный.

## Решение
uv ставит Python 3.12 рядом с системным и управляет окружением. В `pyproject.toml` версии строго как в `requirements.txt`, но разбиты на группы: ядро (≈ 150 МБ, хватает для `solution.py` и тестов), `dev` (pytest, ruff), `research` (графики, ноутбуки), `full` (всё тяжёлое, torch — CPU-сборка).

## Альтернативы
- pip + venv — нет управления версией Python, медленно, нет lock-файла.
- conda — тяжело, долго, другие версии пакетов, чем на платформе.
- Ставить всё сразу — часы скачивания на нашем интернете, онбординг за час невозможен.

## Последствия
- Онбординг: `uv sync` — минуты, а не часы.
- Кто использует пакет из `full` в коде агента — обязан добавить тест, который запускается в CI с `--group full` (задача qa).
- Тест `test_only_allowed_imports` не даёт импортировать то, чего нет в `requirements.txt`.
