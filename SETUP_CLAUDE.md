# Настройка Claude Code под наш проект (10 минут)

Большая часть настройки **уже лежит в репозитории** и включается сама после `git clone`:
`CLAUDE.md` (правила и поведение Claude), `.claude/commands/` (слэш-команды), `.claude/agents/` (сабагенты), `.claude/skills/` (навыки по ролям), `.claude/settings.json` (разрешения, хук форматирования, плагины), `.mcp.json` (сервер документации context7).
У себя нужно: войти, доверить папку, поставить один плагин, проверить. Каждый шаг: **команда → что должно появиться → если не появилось**.

> Claude Code установлен по [docs/install.md](docs/install.md), шаг 4. Все команды ниже — из папки `alfahack-automl`.

## 1. Вход
```
claude
```
→ Выбери вход через аккаунт Claude (подписка Pro), откроется браузер → подтверди.
→ Не открылся браузер: скопируй ссылку из терминала вручную. Ошибка входа — https://code.claude.com/docs/en/troubleshoot-install

## 2. Доверить папку проекта
При первом запуске в папке Claude спросит, доверяешь ли ты ей → **Yes, I trust this folder**.
Без этого не включатся наши разрешения, хук и плагины из `.claude/settings.json` (запреты работают всегда).

## 3. Разрешить сервер документации context7
Claude спросит про MCP-сервер `context7` из `.mcp.json` → **разреши**.
Проверка: в Claude набери `/mcp` → `context7 · connected`.
→ Если сервера нет в списке — выйди (`/exit`), `git pull`, запусти `claude` снова. Если `failed` — проверь интернет; без context7 работать можно, просто Claude будет хуже знать свежие API.

## 4. Поставить командный плагин
Выйди из Claude (`/exit`) и в обычном терминале:
```
claude plugin marketplace add anthropics/claude-plugins-official
claude plugin install commit-commands@claude-plugins-official --scope local
```
→ Должно появиться: `Successfully installed plugin: commit-commands@claude-plugins-official`. Первая команда может ответить, что маркетплейс уже добавлен, — это нормально.
→ Ошибка сети — повтори позже; плагин не блокирует работу.

## 5. Проверить, что всё видно
Запусти `claude` и набери `/` — в списке должны быть наши команды: `/onboard`, `/next-task`, `/sync-check`, `/explain`, `/pre-pr`, `/submit-check`, а также `/commit-commands:commit`.
Набери `/agents` — должны быть `code-reviewer`, `test-writer`, `ml-mentor`.
Из терминала: `uv run python scripts/doctor.py --role <роль>` — раздел «Claude Code» весь ✅.

## 6. Начать
В Claude: **`/onboard`** — он проверит, что осталось, и приведёт к первой задаче.

## Как работать с Claude в команде

| Хочу | Делаю |
|---|---|
| Понять, что делать дальше | `/next-task` |
| Разобраться в коде/термине | `/explain agent/loop.py` или `/explain кросс-валидация` |
| Научиться, а не получить готовое | скажи «режим подсказки» — Claude будет наводить, а код напишешь ты |
| Тест к своему коду | «напиши тест к …» → сабагент `test-writer` |
| Ревью перед PR | `/pre-pr`, потом «отревьюй мои изменения» → `code-reviewer` |
| Поменять контракт | `/sync-check` до правки |
| Совет по ML | «спроси ml-mentor: …» |
| Записать эксперимент | «запиши эксперимент в журнал» (навык `experiment-log`) |

## Как беречь лимиты Pro
- Модель по умолчанию в проекте — **Sonnet** (`.claude/settings.json`). Opus — только на сложное (`/model`), он расходует лимит заметно быстрее.
- Одна задача — один разговор: закончил → `/clear`. Длинный разговор → `/compact`.
- Не проси «прочитать весь проект» и CSV целиком.
- Остаток лимита — `/usage`. Кончился — переходи к ревью чужих PR или документации руками, пиши в чат.

## Опциональные плагины по ролям

Все — из официального маркетплейса `claude-plugins-official` (проверено 20.10.2026). Ставить: `claude plugin install <имя>@claude-plugins-official --scope local`.

| Плагин | Кому | Зачем | Цена |
|---|---|---|---|
| `learning-output-style` | новичкам любой роли | Claude чаще объясняет и просит написать ключевые 5–10 строк самому | ⚠️ добавляет инструкции в каждую сессию — больше токенов |
| `explanatory-output-style` | новичкам | объясняет решения и устройство кода по ходу | ⚠️ тоже стоит токенов |
| `pyright-lsp` | agent, ml, captain | Claude видит типы и ошибки в Python-коде | нужен `pyright`: `uv tool install pyright` ⚠️ при первом запуске качает Node.js — на медленном интернете долго |
| `code-simplifier` | всем | упростить код после того, как он заработал | по вызову |
| `claude-md-management` | captain | держать `CLAUDE.md` в актуальном состоянии | по вызову |
| `pr-review-toolkit` | captain, qa | глубокое ревью PR несколькими агентами | ⚠️ дорого по лимиту — только для важных PR |

**GitHub-MCP мы не используем:** ему нужен личный токен (PAT) в переменной окружения — лишний риск утечки и сложность для новичков. Всё, что нужно (issue, PR, CI), Claude делает через `gh`, который у всех уже авторизован.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Нет наших `/команд` | ты не в папке репозитория или на старой ветке: `cd alfahack-automl && git switch dev && git pull` |
| Claude спрашивает разрешение на каждый `uv run pytest` | не доверил папку (шаг 2): `/permissions` в терминальном `claude` или перезапусти и согласись |
| Хук форматирования ругается | `uv sync` (нужен ruff в окружении). На Windows нужен Git for Windows (Claude запускает хуки через Git Bash) |
| Claude хочет прочитать `.env` | он не сможет — это запрещено настройками. Ключ никогда не отправляй в чат |
| Чат на claude.ai говорит «не вижу репозиторий thenlaooo/alfahack-automl» | это **чат**, а не Claude Code. Чат видит приватный репозиторий только через приложение Claude на GitHub, которое ставит владелец. Работай в **Claude Code** (терминал `claude` в папке проекта или вкладка **Code** в десктопном приложении) — там репозиторий виден через твой `git clone`, и работают наши команды и скиллы |
