# Онбординг за 1 час

**Цель:** через час у тебя всё установлено, `doctor.py` полностью ✅, и ты знаешь свою первую задачу.
**Правило команды:** к задачам кейса приступаем **только** после зелёного `doctor.py`. Застрял на шаге дольше 15 минут — пиши в чат (или подойди к QA/капитану).

Твоя личная инструкция — `START_HERE.md` в ветке `team/<твоё-имя>`: ссылку пришлёт капитан. Этот файл — общий путь для всех.

| # | Шаг | Время |
|---|---|---|
| 1 | Понять, что делаем | 10 мин |
| 2 | Установить инструменты | 20 мин |
| 3 | Получить репозиторий и зависимости | 15 мин |
| 4 | Настроить Claude Code | 10 мин |
| 5 | Проверка готовности | 5 мин |

## Шаг 1. Понять, что делаем (10 мин)

1. Прочитай [README.md](README.md) — 3 минуты.
2. Пролистай [docs/glossary.md](docs/glossary.md): незнакомые слова — там.
3. Посмотри схему агента в [docs/architecture.md](docs/architecture.md) — только первую картинку.

**Итог шага:** можешь одной фразой сказать: «мы делаем агента, который сам решает табличную ML-задачу по описанию и сдаёт файл с ответами».

## Шаг 2. Установить инструменты (20 мин)

Иди по [docs/install.md](docs/install.md), пункты 1–5. **Плюс** ролевые дополнения из `docs/roles/<твоя-роль>.md`, раздел «Установка».

## Шаг 3. Получить репозиторий и зависимости (15 мин)

**3.1. Прими приглашение.** Открой https://github.com/thenlaooo/alfahack-automl/invitations → **Accept invitation**.
→ Должно появиться: страница репозитория открывается.
→ Если «404»: приглашение ещё не отправлено или ник другой — напиши капитану.

**3.2. Склонируй.** Перейди в папку, где хранишь проекты, и выполни:
```
gh repo clone thenlaooo/alfahack-automl
cd alfahack-automl
```
→ Должно появиться: папка `alfahack-automl`, внутри `README.md`. Команда `git branch` показывает `* dev`.
→ Если ошибка доступа: `gh auth status` — ты вошёл не в тот аккаунт?

**3.3. Установи зависимости:**
```
uv sync
```
→ Должно появиться: `Installed N packages`, рядом создана папка `.venv`.
→ Если долго качает — это нормально в первый раз (~150 МБ). Если ошибка — скопируй её в чат.

**3.4. Включи защиту веток у себя:**
```
uv run python scripts/install_hooks.py
```
→ Должно появиться: `✅ Хуки подключены`.

**3.5. Создай файл с настройками:**
- Windows: `copy .env.example .env`
- macOS/Linux: `cp .env.example .env`

→ Должно появиться: файл `.env` в корне. Ключ LLM в него впишет капитан или ты сам по его инструкции — **не через чат**.

## Шаг 4. Настроить Claude Code (10 мин)

Иди по [SETUP_CLAUDE.md](SETUP_CLAUDE.md). В конце в Claude Code набери `/onboard` — Claude сам проверит, что ты прошёл, и подскажет, что осталось.

## Шаг 5. Проверка готовности (5 мин)

```
uv run python scripts/doctor.py --role <твоя-роль>
```
Роли: `captain`, `agent`, `ml`, `research`, `qa`.

→ Должно появиться: список проверок, каждая с ✅, внизу `ГОТОВ К РАБОТЕ`.
→ Если есть ❌: под каждой ❌ напечатана точная команда, как исправить. Выполни её и запусти doctor снова.
→ ⚠️ — не блокирует работу, но прочитай пояснение.

Когда всё ✅ — отметься в issue «CP0: окружение готово» на доске и напиши в чат «doctor зелёный».
