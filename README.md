# alfahack-automl

AI-агент, который сам решает ML-задачи: читает `task.md`, изучает данные, проверяет гипотезы в цикле AutoResearch и сдаёт `submission.csv`. Кейс Альфа Хак «AI-агент для разработки ML-моделей».

> 🚧 Репозиторий в стадии подготовки. Полный README, онбординг и ролевые пакеты появятся в ветке `dev`.

## Где что лежит сейчас

| Путь | Что это |
|---|---|
| `reference/` | Файлы организаторов без изменений: PDF кейса, `baseline.py`, `requirements.txt` |
| `tasks/public/` | Две публичные задачи (регрессия и многоклассовая классификация) в формате платформы |
| `scripts/install_hooks.py` | Ставит git-хук, который не даёт пушить напрямую в `main`/`dev` |
| `scripts/add_member.py` | Подключает нового участника: приглашение, личная ветка, CODEOWNERS |

## Ветки

- `main` — стабильная версия, только через PR от капитана. Каждый сабмит на платформу — тег на `main`.
- `dev` — ветка интеграции, ветка по умолчанию. Сюда идут все PR.
- `team/<имя>` — личная ветка участника с его `START_HERE.md`.
- `<роль>/<задача>` — короткие ветки задач от `dev`.
